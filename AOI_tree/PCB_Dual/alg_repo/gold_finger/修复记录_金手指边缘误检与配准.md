# 修复记录:金手指边缘误检与配准问题

- **日期**: 2026-08-02
- **涉及文件**: `main_pipeline.py`、`peizhun.py`、`seed_extract.py`
- **缓存版本**: `norm_v6` → `norm_v9`(每次预处理逻辑变更均升级缓存键,旧缓存自动失效)

---

## 一、问题背景

金手指区域缺陷检测流水线在多组测试图上暴露出四类问题,按发现顺序依次为:

1. **金手指整块外轮廓四周出现成排误检**,内部指缝边缘不受影响。
2. **`edge_penalty` 参数意外影响内部缺陷检测**(应只作用于外轮廓带)。
3. **肉眼已对齐的两张图,配准后反而整体移位**(错开约一个指条周期)。
4. **取色点取不到金手指、回退 gold 模式后对齐混乱**,检测效果极差。

---

## 二、问题一:外轮廓成排误检

### 根因(用实际图像调试确认)

| # | 原因 | 说明 |
|---|------|------|
| 1 | 掩膜只从良品图提取 | 配准残差使掩膜边缘内侧在待测图上抠到背景,金面 vs 背景差值拉满 |
| 2 | 配准本身失败 | 相位相关得分 0.09(阈值 0.2)、ORB 不达标,程序仅警告就继续,留下 11~18px 系统性纵向错位 |
| 3 | 外轮廓对比度极高 | 1px 的 `shift_tolerance` 包络吸收不了错位;低频光照校正在边界带样本少、最不稳 |

### 修复内容(`main_pipeline.py`)

1. **待测图掩膜 + 掩膜交集**
   - 新增步骤 2.5:在**色彩归一化之前**的 `aligned_test` 上提取待测掩膜(归一化会把背景色整体平移进板面 HSV 范围,曾导致掩膜铺满全图的 bug)。
   - 检测核心区在**块外轮廓带内**取良品/待测掩膜交集,消除"良品是金面、待测因错位抠到背景"的假差异。
   - 内部**不**取交集:异物/污渍会让待测掩膜在缺陷处缺失,全图交集会把真实缺陷像素一起排除(调试中紫色异物点曾因此漏检)。
   - 掩膜面积合理性检查:待测掩膜面积与良品相差超过 ±50% 时自动禁用交集与形状检测。

2. **ECC 精配准**(`refine_alignment_ecc` + `compose_refined_affine`)
   - 在两张掩膜(平滑 alpha 场)上做 ECC 仿射精修,可靠收敛到亚像素精度,同时校正平移/微旋转/微缩放。
   - 与粗配准矩阵**合成为单一仿射**后对原图一次性重 warp,避免二次重采样损失高频细节。
   - 带合理性校验:|旋转| ≤ 5°、缩放 ∈ [0.9, 1.1]、|平移| ≤ 10% 图像尺寸。
   - 本组图实测:相关度 0.99,校正 13px 平移 + 2.4% 纵向尺度差。

3. **边缘带距离衰减阈值**(启用了原先废弃的 `edge_penalty` / `edge_thresh_cap` 参数)
   - 用大核闭运算把指条桥接成"整块",距**块外轮廓** `edge_band` 像素内,判定阈值从 `diff_thresh × (1 + edge_penalty)` 线性衰减回 `diff_thresh`。
   - `edge_thresh_cap` 可给抬高后的阈值设绝对上限,保证边缘严重缺陷(大面积缺金/崩边)仍能报出。
   - 距离按"整块"边界计算,内部指缝边缘不受影响。

4. **掩膜形状差异检测**(`detect_mask_shape_defects`)
   - 交集掩膜在外轮廓带内留下的几何盲区由掩膜对比兜底:一方掩膜超出另一方 `tol_px` 容差带的部分判为缺料/多料。
   - `valid` 掩膜排除配准 warp 视野外区域,避免误报。

### 验证结果(templ2/test2)

- 底部成排误检:39 处 → **0**
- 中部真实异物点(YiWu):保留检出
- 形状检测:76 处 → 7 处(全部对应指尖真实污点/缺口)

## 三、问题二:`edge_penalty` 影响内部检测

### 根因

"整块"闭运算核按固定比例(长边/30)计算,在小图(264×312)上只有 15px,**不够桥接指缝**,整块掩膜碎成 7 块——每个碎块的边界都被当成外轮廓,边缘带切进金手指内部,实测 38.8% 的金面像素被抬高了阈值。

### 修复内容(`main_pipeline.py`)

新增 `_build_block_mask`:

- 闭运算核从 15px 起**翻倍尝试,直到连通域数量不再减少**(指缝桥接成功后数量骤降并稳定;相距很远的独立金区不会被强行合并)。
- 闭运算在缩至 500px 的小图上执行,大核也保持毫秒级。
- 距离场计算前**给块掩膜垫一圈零边界**:金面延伸到图像边界时,图像边缘同样存在 warp 黑边风险,必须一并算作块外轮廓(修复了 ECC 平移后左右边沿出现整条误检的问题)。

### 验证结果

| 图组 | 受抬高阈值影响的金面像素 |
|---|---|
| 264×312 小图 | 38.8% → **0%**(金面铺满画幅,画面内无块边界) |
| 1326×365 | 3.7%(仅指尖与最外侧指条外沿) |

## 四、问题三:已对齐的图被配准移位

### 根因

金手指是周期性条纹(周期约 49.5px):

- 相位相关响应值仅 0.028(阈值 0.2),锁到假峰,给出接近一个周期的错误平移 (45, 28)px。
- ORB 在重复纹理上只有 4 个内点,不达标。
- `peizhun.py` 的老兜底逻辑是**"两个方法都失败就照样套用不可信的相位平移"**——对齐好的图(灰度差 18.4)被硬移错一个周期(恶化到 38.9)。
- ECC 从错误起点出发只能收敛到"错一根指条"的局部最优。

### 修复内容

1. **`peizhun.py` 兜底择优**:相位与 ORB 都不达标时,在恒等变换 / 相位平移 / ORB 仿射等候选中,用降采样灰度图**实测配准残差**,残差最小者生效。`meta["fallback_errors"]` 记录各候选残差,便于排查。
2. **`refine_alignment_ecc` 收敛复核**(`main_pipeline.py`):精修必须真实降低掩膜残差才采纳,防止 ECC 滑进错周期的局部最优。

## 五、问题四:取色失败 + gold 模式对齐混乱

### 根因(三个叠加)

1. **取色 patch 比指条宽**:种子邻域按图像尺寸取 33×33,而指条只有 23px 宽,再准的点击也会混进指缝背景,生成覆盖全图 90% 的垃圾 HSV 范围,看起来就是"取不到"。
2. **gold 模式掩膜糊成一条**:`get_pcb_alpha_mask` 闭运算核按分辨率放大到 21px,超过指缝宽度,61 根指条被桥接成实心带,掩膜拓扑被破坏。
3. **ORB 的 ROI 裁掉了唯一的锚点**:中央 80% ROI 恰好排除了右端的十字基准,只剩周期指条可匹配,错配出 8% 缩放的荒谬仿射,却因内点达标被信任。且两图还有约 0.8% 的横向差分拉伸,错开整数周期后**全图平均残差几乎不变**(真对齐 57.9 vs 假对齐 33.0),普通残差择优也失去分辨力。真实变换由十字基准裁决:dx≈-20(匹配置信度 0.968)。

### 修复内容

1. **`seed_extract.py` 自适应取色 patch**:在多个候选尺寸(4 / 长边×0.003 / 长边×0.006)中选 HSV 分布最均匀(标准差最小)的,自动收缩到点击目标色块内部。
2. **`main_pipeline.py` 闭运算上限**:`get_pcb_alpha_mask` 的闭运算尺寸在原图尺度上限 8px,不再桥接指缝;封闭小孔由 `fill_mask_holes` 兜底。
3. **`peizhun.py` 锚点配准候选 + 独特性加权残差**:
   - `_horizontal_period`:FFT 估计主水平周期(无显著周期返回 None)。
   - `_uniqueness_weight`:独特性权重图 = 与"自身平移一个周期"的差异,周期条纹权重趋零,十字等独特结构权重高。
   - `_distinctive_shift_candidate`:裁出独特性最强的窗口做模板匹配,生成"锚点平移"候选——锚点唯一,平移无歧义。
   - 候选择优的残差用独特性**加权**,让锚点主导判断。
   - **显著性门槛**:锚点密度峰 ≥ 2× 全图均值才启用(实测真锚点 2.9 倍,纯周期图案噪声峰仅 1.3~1.4 倍),纯周期图自动回退原有逻辑。
   - 候选池最终为:恒等 / 相位平移 / ORB 仿射 / NCC 平移(中央大块归一化互相关搜索)/ 锚点平移。

### 回归验证(四组图)

| 图组 | 配准方式 | 掩膜 IoU | 备注 |
|---|---|---|---|
| templ/test(2651px,带十字) | anchor_shift | 0.937 | 锚点锁定 (-20,-2),ECC 补 0.8% 差分拉伸 |
| 5/6.png(990px,纯周期) | 恒等 + ECC | 0.951 | 候选择优正确选恒等 |
| 3/4.png(264px,金面铺满) | 相位相关 | 0.962 | 常规路径不受影响 |
| templ2/test2(1326px) | ncc_shift | 0.961 | 检出结果与修复前一致 |

## 六、当前参数速查(`main()` 第 4 步)

| 参数 | 当前值 | 作用与调法 |
|---|---|---|
| `diff_thresh` | 20 | 差值判定阈值,误检多调大、漏检调小 |
| `min_defect_area` | 5 | 最小缺陷面积(px) |
| `shift_tolerance` | 1 | 配准残余偏移容差(px) |
| `edge_margin` | 1 | 掩膜边界向内不参与判定的像素数 |
| `edge_band` | 自适应(长边/300,下限 6) | 块外轮廓阈值渐变带宽 |
| `edge_penalty` | 1.0 | 块最外沿阈值 = `diff_thresh × (1+edge_penalty)`,仅作用于块外轮廓带;外边缘误检残留可调回 2.0~3.0 |
| `edge_thresh_cap` | None | 抬高阈值的绝对上限,担心漏边缘大缺陷时设 80 左右 |
| `shape_tol`(步骤 4.5) | 自适应(长边/800,下限 2) | 形状检测容差,指尖污点不算缺陷时调大到 6~8 |
| `shape_min_area` | 自适应 | 形状缺陷最小面积,误报碎块时调大 |

## 七、使用注意

- 预处理缓存键含版本号,重跑自动重算,无需手动删缓存。
- 更换良品图后,seed 取色配置(`pipeline_results/_seed_ranges.json`)会自动失效并重新弹窗;取色时在指条上点 2~3 个点即可。
- 配准信息可查 `meta`:`method`(phase / orb_affine / ncc_shift / anchor_shift / lowconf_*)、`fallback_errors`(各候选实测残差)、`ncc_peak`。
