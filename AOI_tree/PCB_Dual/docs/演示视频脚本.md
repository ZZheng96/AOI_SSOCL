# PCB_Dual + AOI_Core UI 操作演示视频脚本

- 数据：`data_local/extra_part`（4096×3000；`*_temp.jpg` 良品，`*_img.jpg` 多件）
- 驱动：`tests/_demo_record.py`（真实窗口、真实控件点击；弹窗可见并自动应答；字幕烧录进画面）
- 运行：PCB_Dual 目录下 `$env:DEMO_RECORD="1"; e:\CPIPC\CGAIC\.env\Scripts\python.exe tests\_demo_record.py`
- 输出：`docs/演示视频/演示_YYYYmmdd_HHMMSS.mp4`（1920 宽，8fps；长等待段延时摄影并标注"加速"）
- 前置：清空演示数据与 extra_part 模型（使 dual 门禁"品类模型尚未准备"可被拍到）
