# 项目视频录制脚本 v2（≤5 分钟 / ≤200M / mp4）

> 开放赛题五：AI引领制造业的智能化升级 · 队名：AI火眼工坊
> 命名（提交时）：`AI火眼工坊_持续自学习AOI主干融合传统CV双引擎的PCB智能质检平台_项目视频.mp4`。
> **红线**：视频画面、字幕、旁白中不得出现学校、学院、导师等影响比赛公平的信息；不得出现本机用户名路径（如 `C:\Users\xxx`）。

## v2 核心策略（2026-09-01，与企业版相同）

**逐分镜独立录制 + 逐 clip 烧字幕后拼接 —— 字幕画面 1:1 天然对应**：

1. 每分镜独立录一个 mp4（2s 引导 + 正片 + 1s 余量，剪辑裁 `ss=2`）。
2. 每个 clip 只烧它自己那一条字幕（贯穿全程），无全局时间轴，杜绝错位。
3. **AOI 素材与企业版一次录制、两版共用**：本版用 `-t` 裁短（下表"开放时长"列），
   仅字幕按开放赛题口径重写；PCB_Dual 六个页签单独录制（本版独有分镜）。
4. 驱动脚本：
   - AOI 分镜：`cd d:\CGAIC\AOI_sys && python tests\_record_shots_v2.py`（与企业版同一批素材）
   - PCB 分镜：`cd d:\CGAIC\PCB_Ins_v2 && python tests\_record_shots_v2.py`
   - 成片：`python d:\CGAIC\AOI_sys\docs\视频录制素材\raw\v2\build_video.py open`

## 二、录制执行

```powershell
# AOI 分镜（若企业版已录则跳过，素材共用）
cd d:\CGAIC\AOI_sys && python tests\_record_shots_v2.py
# PCB 分镜（窗口标题「PCB 缺陷检测系统」）
cd d:\CGAIC\PCB_Ins_v2 && python tests\_record_shots_v2.py
# 成片（裁短 + 换开放版字幕 + 拼接 + 校验）
python d:\CGAIC\AOI_sys\docs\视频录制素材\raw\v2\build_video.py open
```

- PCB 自动检测页录制前必须已选模板「SMT 焊点示例 v1」（标准图 1317×545，检测项：多锡/少锡/连锡/虚焊）。
- NG 样例图：`PCB_Ins_v2/alg_repo/smt/test_images/excess_pair/pair4/PixPin_2026-07-01_11-21-15.png`（多锡，双引擎均有产出）。

## 三、录制前检查清单

1. [ ] 清空无关窗口/通知；AOI 窗口在录 PCB 分镜时最小化（避免同屏干扰）
2. [ ] AOI 素材已齐（raw/v2/clips/ 14 个分镜 mp4 且校验通过）
3. [ ] PCB 系统 8021 健康检查 ok；模板「SMT 焊点示例 v1」为已发布状态
4. [ ] 导出后核对：总时长 ≤300s、mp4、≤200M、无学校/导师信息、无用户名路径

## 四、后期与校验

- AOI clip 裁短：`-ss 2 -t <开放时长>`；PCB clip 同法；逐 clip 烧字幕后 concat `-c copy`。
- 口径红线：GPU 数字一律带"模型段"口径（p50 58ms/均值 102ms）；CPU 351ms 为全链路均值；
  单图 1s 红线为产线统一约束；跨域 0.60→0.72 不承诺所有品类单调；L3 模板 1.0 仅限金样板覆盖条件。
- 成片抽查：ffprobe 时长/分辨率；抽帧查亮度与字幕文本对应。
