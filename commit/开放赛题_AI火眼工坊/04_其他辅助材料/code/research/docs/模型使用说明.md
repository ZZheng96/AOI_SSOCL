# Demo5 模型使用说明（赛题交付物：§9.2 / 赛题要求 5）

> 版本：v1.0（2026-08-15）· 配套设计文档：`demo5设计.md`（v3.3 + 后续增补）

## 1. 系统概述

可自学习的 AOI 实时在线 AI 质检系统。核心形态：

- **槽位制专家**：7 个评分槽位（sem/disc/blob/trad/layout/inp/tpl）+ E_open 完备性哨兵，统一契约 `score_tiles -> (tile_scores, heatmaps)`，热插拔；
- **场景分层**：L0 零样本 / L1a 图像级标注（赛题标准，≤100 正常+≤30 缺陷）/ L1b 定位标注 / L2 限定品类 / L3 显式模板——同一管线按可用信息激活槽位；
- **在线 SSOCL**：三类反馈（判对/判错/无反馈）驱动双库制（锚定+扩展）+ 缺陷样例近邻拦截 + 主动学习 + 归因决策树 + 回归门控回滚；
- **分层输出**：L1 判定 → L2 定位（检测框+像素掩码）→ L3 类型归因 → L4 追溯。

## 2. 安装与依赖

- Python 3.11、PyTorch ≥2.1（CUDA）、torchvision、opencv-python、numpy、scikit-learn、scikit-image、pyyaml、matplotlib
- GPU：GTX 1660 SUPER 及以上（2060 同理）；CPU 降配模式见 §6
- 数据：GYU-DET、data_local（`D:\CGAIC\data_origin\GYU-DET`、`D:\CGAIC\data_local`）；DINOv2 本地 hub 缓存（无网络可跑）

## 3. 数据协议（红线强制）

- 目录结构（data_local）：`{category}/{train/good, val/{good,defect}, test/...}`
- 训练：`init_normal` 全部来自 **train 域**（≤100 张正常）+ `init_defect`（≤30 张缺陷，赛题协议）
- **红线断言**（`src/common/isolation.py`）：test/good、配对参考、文件名元信息进入 fit 即报错
- 缺陷类型目录名即类型标签（类型归因评测用）

## 6. CPU 降配（挑战目标）

```bash
python scripts/exp_cpu_speed.py --category gold_finger   # 用 configs/m4_cpu.yaml
```

纯手工槽位（blob/trad/layout），无主干、无网络。实测 2500² 级 CPU e2e mean 351ms / p95 368ms/图（n=15 复测 2026-08-31，`outputs/m0/bench_2500_cpu.json`，<2s 达成），精度劣化如实报告（blob 单槽最强）。

## 7. 在线反馈接口（SSOCL）

```python
pipe.enable_ssocl(ssocl_cfg, train_normal_paths=bundle["init_normal"])
pipe.feedback(path, verdict="correct"|"wrong"|"none", label=0|1)  # 三类反馈
pipe.active_select(top_n=10)          # 主动选样询问清单
pipe.handler.stats                    # reflow/defect_add/router_ft/rollback 统计
```

生效路径：判错缺陷 1 张入库 → 近邻拦截即时生效（秒级，"这批错检下批检对"实测 F1 +0.37~0.48）；正常回流成簇入库 + CDF 重估，锚定集回归门控回滚。

## 8. 追溯 API（回溯检测逻辑）

```python
api = pipe.attach_trace_api("outputs/m0/trace_api")
api.recent_inferences(20)   # 逐样本 slot_scores/fused/decision/boxes/types
api.update_log()            # 反馈/回滚/回归门控历史
api.system_state()          # 权重/阈值/双库版本/熔断状态
```

## 10. 参数预算（小模型响应）

- DINOv2 主干：22M，永冻（共享特征提取）
- 可训练参数：disc 头 + 线性路由 + AHL 孵育头 <0.5M（在线更新只动这些）
- 无梯度组件：记忆库/kNN/PCA/布局统计/CDF 表（纯检索统计）

## 11. 已知边界（诚实声明）

- **速度**：图片全分辨率 3000×4096 实测 0.7-0.8s/图；2500² <200ms 目标需 ONNX/TensorRT 工程杠杆（设计 §6.1 已列路径，未实施）
- **gold_finger 弱检测**：域差+微缺陷，融合层 AUROC 0.43-0.49（blob 单槽 0.71）；出路=粒度/在线拦截/tpl 模板
- **时序边界**（U7）：视频"顺序错误"仅关键帧+平滑，无时序建模
- **PDN 蒸馏不采纳**（U9）：学生特征质量不足，CPU 路径走纯手工槽位
