# 项目视频录制脚本 v2（≤5 分钟 / ≤200M / mp4）

> 企业赛题-华为赛题一：可自学习的AOI实时在线AI质检 · 队名：火眼工坊
> 依据《第八届初赛作品提交规范》：项目视频用于"核心目标预期效果展示"，≤5 分钟、≤200M、mp4。
> 命名（提交时）：`火眼工坊_可自学习的AOI实时在线AI质检系统_项目视频.mp4`。
> **红线**：视频画面、字幕、旁白中不得出现学校、学院、导师等影响比赛公平的信息；不得出现本机用户名路径（如 `C:\Users\xxx`）。

## v2 重做原因与核心策略（2026-09-01）

v1 问题：长段录制 + 后期按全局时间轴烧字幕，操作节奏与字幕时间轴靠手工对齐，易漂移；
且未覆盖全部 10 个导航页（缺数据增强/评估看板/系统设置）。

**v2 策略：逐分镜独立录制 + 逐 clip 烧字幕后拼接 —— 字幕画面 1:1 天然对应**

1. 每个分镜用 ffmpeg gdigrab 按窗口标题独立录一个 mp4，固定时长（`-t`），
   录 2s 引导 + 正片 + 1s 余量，剪辑时裁 `ss=2` 取正片，分镜起点即操作起点。
2. 字幕在**拼接前**逐 clip 烧录：每个 clip 只烧它自己那一条字幕（贯穿该 clip 全程），
   不存在全局时间轴，**杜绝字幕与画面错位**。
3. AOI 素材一次录制，企业版/开放版两版共用（开放版用 `-t` 裁短，见开放版脚本）。
4. 驱动脚本自动完成"切页 + 页内操作 + 启停 ffmpeg"：
   `cd d:\CGAIC\AOI_sys && python tests\_record_shots_v2.py`
   （终端逐分镜输出进度；素材落 `AOI_sys/docs/视频录制素材/raw/v2/`）。

```powershell

# 2. 逐分镜录制（终端有 [shot] 进度，单分镜失败可重跑单个）
cd d:\CGAIC\AOI_sys
python tests\_record_shots_v2.py            # 全录
python tests\_record_shots_v2.py 07_monitor # 只重录某分镜
# 3. 剪辑成片（裁引导 + 逐 clip 烧字幕 + 拼接 + 校验）
```

## 四、后期与校验

- 每个 clip：`ss=2 -t <正片时长>` 裁掉引导，烧该分镜唯一字幕后 concat（同参数字段，`-c copy`）。
- 成片抽查：ffprobe 时长/分辨率；抽帧查亮度（非黑帧）；抽帧核对字幕文本与画面对应。
- 关键数字字幕：87.8ms 基准、p50 58ms/均值 102ms、0.60→0.72、MVTec 0.9793、参数 <0.5M。

## 五、v2 实测踩坑记录（2026-09-01，重要发现）

1. **ops 必须 QTimer 调度，不能同步循环里直接调**：`dlg.exec()` 类弹窗 op（新建数据源/准备模型/反馈对话框）
   会把主线程调用栈阻塞在嵌套事件循环里，后续 op 永远执行不到（首跑 03_datasource 卡死 14 分钟）。
   QTimer 在嵌套循环里照常触发，「取消/提交」op 可正常关窗。
2. **gdigrab `title=` 只录主窗口像素，录不到模态弹窗**（弹窗是独立顶层窗口，首跑 03/05/08 弹窗全丢）。
   含弹窗分镜改录桌面固定区域：`-offset_x 30 -offset_y 20 -video_size 1440x900 -i desktop`
   （窗口 move(30,20) 与区域对齐），即 `_record_shots_v2.py` 的 `DESKTOP_SHOTS`。
3. 静态卡底部小字须避开成片字幕位置（字幕 y=h-95，卡片 footer 提到 h-170）。
4. 工作台顶部 KPI 大字是"全部时间范围"累计口径，与工单行数字不同 —— 字幕不要引用具体数字，避免观感冲突。
