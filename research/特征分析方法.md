**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">只看最终 AUC 并不完全可靠。AUC 是 “结果指标”，只能告诉你整套流水线好不好；但无法回答：特征本身到底行不行、有没有区分能力，容易出现「特征垃圾，靠后处理硬凑出不错 AUC」的假象。</font>**

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">我们分三层讲清楚，结合你的场景：传统手工特征 / DINOv2 特征 / ResNet 特征。</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一、先讲：只依赖 AUC 会踩什么坑？</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">举几种现实里很常见的陷阱：</font>

1. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">数据集分布偏见</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 比如良品画面高度单一，缺陷极其醒目。哪怕特征很粗糙，随便算距离也能分出高低，AUC 看上去很漂亮；换一批稍微多变的良品直接崩盘。</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> AUC 只反映当前测试集，不代表特征本身具备通用区分能力。</font>
2. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">后处理救烂特征</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 特征本身区分度很差，但是你加复杂 MLP 多头、大量增强、阈值调优，强行拟合出边界。</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 推理：真正起作用的是 MLP 拟合能力，</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">不是特征本身富含判别信息</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">。一旦域偏移（光照、相机轻微变动），直接失效。</font>
3. **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">全局指标掩盖局部缺陷</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 整张图 AUC 很好，但微小缺陷对应的 patch 特征完全分不开；</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 你后续想要缺陷定位时，热力图一团乱，此时全局 AUC 欺骗了你。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">AUC = 整套系统的综合得分</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> ≠ 特征向量本身具备良好类内聚集、类间分离特性</font>

## <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">二、如何单独评估「特征本身质量」（脱离打分头、距离函数，直接评价特征）</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">一套标准流程，分成可视化指标 + 数值指标，不用依赖最终 AUC：</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">1. 基础数值指标（对特征向量直接计算）</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">设：正常样本特征集合 N，异常特征集合 A</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 1）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">类内距离（良品簇紧不紧密）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 所有良品特征互相之间距离均值；越小越好。</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 理想：同类良品特征挤成一团。</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 2）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">类间距离（良品与异常离得远不远）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 良品中心到各类异常特征的距离；越大越好。</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 3）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">分离度指标：DBI（戴维斯 - 博尔丁指数）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> DBI 越小 → 簇内紧凑、簇之间分得开，是聚类层面标准特征质量指标。</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 4）</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">特征相似度分布直方图（最实用）</font>**

+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">良品样本和良品特征库的距离分布</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">良品样本和缺陷样本的距离分布</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 画出两条分布曲线</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">✅</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 两条曲线错开、重叠区域很小 → 特征有效</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">❌</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 大面积重叠 → 特征本身区分能力弱，AUC 再好也是假象</font>

### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">2. 降维可视化（最直观，工程首选）</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">把高维特征（384/512 维）降到 2 维：</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 使用 </font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">t-SNE / UMAP</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 绘图规则：</font>

+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">蓝色：正常样本特征</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">红色：各类缺陷特征</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">肉眼判断标准：</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">✅</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 所有蓝色聚拢在一起；红色散落、和蓝色区块明显分开 → 特征质量优秀</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">⚠️</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 红蓝大量穿插混杂 → 特征本身区分度不足</font><font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 哪怕你训练 MLP 跑出不错 AUC，上线很容易翻车。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">你可以同时画图对比：传统手工特征 VS DINOv2 特征，直观看到谁聚类更好。</font>
