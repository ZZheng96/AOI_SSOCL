## 第一部分：通用底层视觉特征的深度展开

### 总览：五类通用底层视觉特征

人类质检员抛开零件外形大小，统一判断表面缺陷，依靠的是五类**与物体种类无关**的底层视觉信号：

| 特征类 | 一句话本质 | 异常时的表现 |
|--------|-----------|------------|
| ① 局部纹理排布 | 纹理的规律性重复 | 规律被打破（划痕切断纹理） |
| ② 细小边缘连续性 | 边缘的平滑连贯 | 边缘断裂/错位（裂纹、毛刺） |
| ③ 材质反光光泽 | 反光的均匀一致 | 局部反光突变（凹坑、油污） |
| ④ 像素灰度波动 | 灰度的稳定分布 | 灰度异常跳变（黑斑、亮点） |
| ⑤ 区域自相似性 | 局部与邻域相似 | 局部"格格不入"（异物、缺料） |

下面逐一深度展开：物理含义 → 传统数学表征 → 神经网络如何编码 → 缺陷信号 → 提取方法。

### 特征 ①：局部纹理排布（Local Texture Arrangement）

#### 物理含义
纹理是像素在局部区域的**重复性排布模式**。每种工业产品表面都有固有纹理：
- 纺织品：经纬交织的网格纹理
- 金属拉丝：方向性条纹纹理
- 注塑塑料：注塑纹/流纹
- PCB板：焊盘与走线的规则排布
- 屏幕：像素点阵

正常纹理有**规律性的重复**（自相关性强），缺陷会打破这种规律。

#### 传统数学表征
| 方法 | 计算内容 | 异常信号 |
|------|---------|---------|
| 灰度共生矩阵 GLCM | 统计特定方向/距离的灰度共现概率 | 能量/对比度/相关性突变 |
| 局部二值模式 LBP | 编码中心像素与邻域的大小关系 | LBP直方图偏离正常 |
| Gabor 滤波器组 | 多方向多频率的纹理响应 | 某方向/频率响应异常 |
| 自相关函数 | 纹理的周期性强度 | 周期性被破坏 |

#### DINOv2 如何编码
- ViT 将图像切为 14×14 patch，每个 patch token 天然编码局部纹理模式
- **中层特征（第 2-9 层）对纹理最敏感**（Dinomaly 实验验证：中间层含低级视觉特征，利于精确定位）
- DINOv2 的 MIM 预训练（掩码恢复）强迫模型理解纹理的局部结构

#### 缺陷在此特征上的表现
| 缺陷类型 | 纹理变化 |
|---------|---------|
| 划痕 | 切断原有纹理走向 |
| 污渍 | 覆盖原有纹理（纹理消失） |
| 裂纹 | 引入新的不规则纹理 |
| 腐蚀 | 纹理变粗糙/无规律 |

#### 提取方法
```python
# 方法1：DINOv2 patch 特征（推荐，通用）
features = dinov2(image)  # [N_patches, D], D=384
# 每个 patch 特征已编码该区域的纹理模式

# 方法2：传统 GLCM（可解释性强，适合文档）
from skimage.feature import graycomatrix, graycoprops
glcm = graycomatrix(gray_img, distances=[1,2], angles=[0,45,90,135], levels=256)
contrast = graycoprops(glcm, 'contrast')  # 对比度
energy = graycoprops(glcm, 'energy')      # 能量（规律性）

# 方法3：Gabor 滤波器组
from skimage.filters import gabor
filt_real, filt_imag = gabor(gray_img, frequency=0.1, theta=0)
```

### 特征 ②：细小边缘连续性（Fine Edge Continuity）

#### 物理含义
工业产品表面的边缘应当**连续平滑**：
- 零件轮廓线连续
- 印刷线条无断笔
- 焊接缝均匀
- 切割边缘无毛刺

缺陷会导致边缘**断裂、错位、毛刺**。

#### 传统数学表征
| 方法 | 计算内容 | 异常信号 |
|------|---------|---------|
| Canny/Sobel 边缘 | 梯度幅值与方向 | 边缘断裂/方向突变 |
| 边缘方向直方图 | 边缘方向的统计分布 | 分布异常偏移 |
| Hough 变换 | 检测直线/圆等几何结构 | 结构缺失/变形 |
| 边缘连接性度量 | 边缘像素的连通性 | 连通性断裂 |

#### DINOv2 如何编码
- ViT 的**自注意力机制**捕捉边缘的跨 patch 连续性
- **高分辨率预训练（518×518）**使 DINOv2 能保留细小边缘（Dinomaly 实验证明输入尺寸越大，定位越准）
- CL 预训练使模型理解"边缘应该连续"

#### 缺陷信号
| 缺陷 | 边缘变化 |
|------|---------|
| 裂纹(crack) | 出现新的不规则边缘 |
| 断裂(broken) | 原有边缘断裂 |
| 错位(misplaced) | 边缘位置偏移 |
| 毛刺(burr) | 边缘出现锯齿 |

#### 提取方法
```python
# 方法1：DINOv2 特征的边缘敏感通道（间接）
features = dinov2(image)
# 注意：DINOv2 特征是混合的，边缘信息编码在特定维度

# 方法2：Sobel 梯度（直接，可解释）
import cv2
grad_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
grad_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
edge_magnitude = np.sqrt(grad_x**2 + grad_y**2)
edge_direction = np.arctan2(grad_y, grad_x)

# 方法3：Canny + 连通性分析
edges = cv2.Canny(gray, 50, 150)
# 分析边缘连通性，断裂处 = 异常
```

### 特征 ③：材质反光光泽（Material Reflectance & Gloss）

#### 物理含义
不同材质有特定的**反光模式**（BRDF - 双向反射分布函数）：
- 金属：镜面反射强（高光锐利）
- 塑料：漫反射+弱镜面
- 玻璃：透射+镜面
- 哑光表面：纯漫反射

正常表面反光**均匀一致**，缺陷改变局部反光特性。

#### 传统数学表征
| 方法 | 计算内容 | 异常信号 |
|------|---------|---------|
| 梯度方向分布 | 反光方向的统计 | 异常高光/漫反射区 |
| 高光区域检测 | 镜面反射区域 | 异常高光点 |
| 频域高频成分 | FFT 高频能量 | 表面粗糙度突变 |
| 局部对比度 | 局部明暗变化 | 反光不均匀 |

#### DINOv2 如何编码
- DINOv2 在 1.42 亿张自然图像预训练中学会了**材质识别**（这是自监督学习的副产品）
- 特征中某些维度专门编码材质属性
- Register Tokens 消除反光 artifact，使特征更干净

#### 缺陷信号
| 缺陷 | 反光变化 |
|------|---------|
| 凹坑(dent) | 产生异常高光点/阴影 |
| 氧化(oxidation) | 镜面反射变漫反射 |
| 油污(oil) | 产生异常光斑 |
| 磨损(wear) | 表面粗糙度增加 |

#### 提取方法
```python
# 方法1：频域分析（反光=高频成分）
fft = np.fft.fft2(gray)
fft_shift = np.fft.fftshift(fft)
magnitude = np.log(np.abs(fft_shift) + 1)
high_freq_energy = magnitude[high_freq_mask].mean()  # 高频能量

# 方法2：局部对比度（反光不均匀）
from skimage.filters.rank import contrast_enhancement
local_contrast = cv2.intensity.contrast(gray, kernel)

# 方法3：高光检测
highlight_mask = (gray > 220)  # 高阈值
highlight_area = highlight_mask.sum()
```

### 特征 ④：像素灰度波动（Pixel Intensity Fluctuation）

#### 物理含义
正常表面的灰度在一定范围内**稳定波动**（噪声级波动）。缺陷导致局部灰度**突变**：
- 暗点：凹坑、黑斑、异物（深色）
- 亮点：高光、气泡、异物（浅色）
- 渐变：污渍、变色

#### 传统数学表征
| 方法 | 计算内容 | 异常信号 |
|------|---------|---------|
| 局部均值/方差 | 滑窗统计量 | 均值/方差突变 |
| 直方图统计 | 灰度分布 | 分布偏离正常 |
| 小波分解 | 多尺度频率成分 | 某尺度异常 |
| 控制图理论 | 统计过程控制 | 超出控制限 |

#### DINOv2 如何编码
- patch token 的**全局池化值**间接反映局部灰度统计
- 但 DINOv2 特征是高维语义特征，不直接保留原始灰度值
- **建议与传统统计方法结合**：DINOv2 语义 + 原始灰度统计

#### 缺陷信号
| 缺陷 | 灰度变化 |
|------|---------|
| 黑斑 | 局部灰度骤降 |
| 亮点/气泡 | 局部灰度骤升 |
| 变色 | 灰度分布偏移 |
| 污渍 | 局部方差增大 |

#### 提取方法
```python
# 方法1：局部统计（最直接）
from skimage.filters.rank import mean, std
local_mean = cv2.intensity.mean(gray, kernel)
local_std = cv2.intensity.std(gray, kernel)
# 局部均值/方差偏离正常范围 = 异常

# 方法2：小波分解
import pywt
coeffs = pywt.wavedec2(gray, 'db4', level=3)
# 某层细节系数异常大 = 该尺度有缺陷

# 方法3：DINOv2 + 灰度统计融合
dino_feat = dinov2(image)         # 语义特征
gray_stat = compute_local_stats(gray)  # 灰度统计
fused = concatenate(dino_feat, gray_stat)  # 融合
```

### 特征 ⑤：区域自相似性（Regional Self-Similarity）

#### 物理含义
很多工业产品表面具有**自相似结构**：
- 周期性纹理（布料、网格）
- 重复图案（PCB 焊盘阵列）
- 规则结构（螺丝螺纹、拉链齿）

正常区域与邻域**高度相似**，缺陷区域与邻域**不同**（"格格不入"）。

#### 传统数学表征
| 方法 | 计算内容 | 异常信号 |
|------|---------|---------|
| 块匹配 | 与邻域块的相似度 | 相似度低 |
| 互相关 | 与邻域的相关系数 | 相关性低 |
| 非局部均值 | 加权邻域去噪残差 | 残差大 |
| 自相似描述子 | 重复模式检测 | 模式被打破 |

#### DINOv2 如何编码
- ViT 的**全局自注意力**天然捕捉长程依赖和区域间相似性
- 每个 patch token 可以"看到"图像所有其他 patch
- 异常 patch 与正常 patch 的注意力模式不同 → 可检测

#### 缺陷信号
| 缺陷 | 自相似性变化 |
|------|------------|
| 异物 | 异物区域与背景不相似 |
| 缺料 | 缺料区域与邻域不同 |
| 变形 | 结构周期性被打破 |
| 色差 | 局部颜色与邻域不同 |

#### 提取方法
```python
# 方法1：DINOv2 patch 间相似度（推荐）
features = dinov2(image)  # [N_patches, D]
sim_matrix = cosine_similarity(features)  # [N, N]
# 每个 patch 与最相似 patch 的距离 = 自相似性分数
self_sim = 1 - sim_matrix.max(axis=1)  # 距离越大越异常

# 方法2：传统块匹配
from skimage.util import view_as_blocks
blocks = view_as_blocks(gray, (block_size, block_size))
for block in blocks:
    # 与邻域块比较
    neighbor_dist = compute_distance(block, neighbors)
    if neighbor_dist > threshold:  # 与邻域不相似
        flag_anomaly(block)

# 方法3：非局部均值残差
from skimage.restoration import denoise_nl_means
denoised = denoise_nl_means(gray)
residual = gray - denoised  # 残差大 = 异常
```

### 五类特征的总览：如何组合使用

```
原始图片
    ├──→ [DINOv2 patch特征] ──→ 编码①②③⑤（语义级，通用）
    │
    ├──→ [灰度统计] ──→ 编码④（像素级，直接）
    │
    ├──→ [边缘梯度] ──→ 编码②（边缘连续性，可解释）
    │
    └──→ [频域分析] ──→ 编码③（反光/粗糙度，物理级）
    
融合 → 统一异常分数 + 像素级热力图
```

**关键洞察**：DINOv2 特征已经隐式编码了①②③⑤的大部分信息（因为 1.42 亿图预训练），但④（像素灰度波动）这种低级统计信息在 ViT 高维语义特征中可能被"稀释"。因此**最佳实践是 DINOv2 语义特征 + 传统低级特征融合**。

## 第二部分：多模态大模型 API 用于训练的方案

### 可行性分析

首先要澄清"训练"的含义：

| 含义 | 可行性 | 原因 |
|------|--------|------|
| 微调大模型本身 | ❌ 不可行 | API 不提供微调接口；即使有也极贵 |
| 用大模型做零样本推理 | ⚠️ 不适合赛题 | 延迟秒级，远超 200ms；像素级定位弱 |
| 用大模型辅助训练小模型 | ✅ 可行 | 离线用大模型，在线用小模型 |

**结论**：多模态大模型 API **不能用于在线推理**（赛题要求 <200ms），但可以**用于离线训练阶段**，从四个方向赋能小模型。

### 四种应用方案

#### 方案 A：大模型做蒸馏教师（Knowledge Distillation）

**思路**：用多模态大模型（GPT-4V/Gemini）对工业图片生成详细的"正常/异常描述"，用这些描述训练小模型理解缺陷语义。

```
离线阶段：
  工业图片 → GPT-4V API → "这张图左上角有一条约2mm的划痕，
                            方向45度，切断了原有拉丝纹理"
       ↓
  [描述文本] → CLIP文本编码器 → 文本嵌入
  [工业图片] → DINOv2 → 视觉特征
       ↓
  训练小模型：视觉特征 → 预测文本嵌入（对齐）

在线阶段：
  测试图片 → 小模型(DINOv2+检测头) → 异常分数 + 缺陷描述
```

**优势**：让小模型继承大模型的缺陷理解能力
**劣势**：API 调用成本高（每张图约 $0.01-0.05）、需要大量图片标注

#### 方案 B：大模型生成伪异常数据（Synthetic Anomaly Generation）⭐ 推荐

**思路**：用 Stable Diffusion / DALL-E / ControlNet 生成逼真的缺陷图片，扩充训练数据。用 GPT-4V 验证生成质量。

```
离线阶段：
  ① 正常图片 + 缺陷描述 → ControlNet → 生成缺陷图片
     例：正常螺丝图 + "在螺纹处添加横向裂纹" → 带裂纹螺丝图
  
  ② GPT-4V 验证：判断生成图片是否逼真、缺陷位置是否合理
  
  ③ 将生成的(缺陷图, 掩码)对加入训练集

在线阶段：
  测试图片 → 小模型(用增强数据训练) → 异常检测
```

**具体操作**：
```python
# 用 Stable Diffusion + ControlNet 生成缺陷
from diffusers import StableDiffusionControlNetPipeline, ControlNetModel

controlnet = ControlNetModel.from_pretrained("lllyasviel/sd-controlnet-canny")
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", controlnet=controlnet
)

# 正常图的边缘作为控制条件
normal_edges = cv2.Canny(normal_img, 50, 150)

# 生成缺陷图
prompt = "industrial surface with a scratch defect, realistic, high quality"
defect_img = pipe(prompt, image=normal_edges).images[0]

# 用 GPT-4V 验证质量
# response = gpt4v_api(defect_img, "Does this image show a realistic scratch defect?")
```

**优势**：
- 解决少样本问题（30 张异常 → 生成 3000 张）
- 可控缺陷类型、位置、严重程度
- 与 AHL 的 HADG 伪异常生成互补

**劣势**：
- 生成质量依赖 prompt 工程
- 需要 GPU 跑扩散模型

#### 方案 C：大模型做自动标注（Auto-Labeling）

**思路**：用 GPT-4V 对未标注的工业图片做自动异常检测和标注，生成训练数据。

```
未标注图片 → GPT-4V API → "图片有异常，位置在(x,y,w,h)，类型=划痕"
       ↓
自动标注框/掩码 → 加入训练集 → 训练小模型
```

**优势**：减少人工标注成本
**劣势**：GPT-4V 的像素级定位能力弱，标注质量参差不齐

#### 方案 D：大模型做特征提取器（Feature Extractor）⚠️ 不推荐

**思路**：直接用 CLIP/多模态大模型的视觉编码器提特征。

**问题**：
- 闭源 API（GPT-4V）不暴露中间特征，只返回文本
- 开源模型（CLIP/DINOv2）可本地部署，比 API 更好更快
- **应该直接用 DINOv2 本地部署，而非调 API**

### 推荐组合方案

```
┌─────────────────────────────────────────────────────────┐
│  离线训练阶段（用大模型 API 赋能）                        │
│                                                         │
│  ① Stable Diffusion + ControlNet 生成伪异常数据          │
│     └── 扩充 30 张异常 → 3000 张（方案B）               │
│                                                         │
│  ② GPT-4V 验证生成质量 + 自动标注（方案A+C）             │
│     └── 生成缺陷描述文本 → 蒸馏给小模型                  │
│                                                         │
│  ③ 用增强数据训练小模型：                                │
│     └── DINOv2 特征 + Dinomaly 框架 + AHL 精判          │
├─────────────────────────────────────────────────────────┤
│  在线推理阶段（纯本地小模型，不调 API）                   │
│                                                         │
│  测试图片 → DINOv2-S(21M) + Dinomaly检测头 → <200ms     │
│  满足 2060 GPU 实时要求                                  │
└─────────────────────────────────────────────────────────┘
```

### 成本估算

| 项目 | 用量 | 单价 | 成本 |
|------|------|------|------|
| GPT-4V 标注 1000 张 | 1000 次 | ~$0.05/次 | ~$50 |
| Stable Diffusion 生成 3000 张 | 本地 GPU | 免费 | 0 |
| **总 API 成本** | | | **~$50** |

## 第三部分：对赛题方案的具体建议

### 特征提取的具体实现

```python
class UniversalFeatureExtractor:
    """通用底层视觉特征提取器：DINOv2语义 + 传统低级特征"""
    
    def __init__(self):
        # DINOv2-S/14（21M参数，2060可实时）
        self.dinov2 = torch.hub.load('facebookresearch/dinov2', 'dinov2_vits14')
        self.dinov2.eval()
    
    def extract(self, image):
        """提取五类通用底层视觉特征"""
        gray = cv2.cvtColor(image, cv2.COLOR_RGB2GRAY)
        
        # ①②③⑤ DINOv2 语义特征（隐式编码纹理/边缘/反光/自相似）
        with torch.no_grad():
            dino_feat = self.dinov2(image_tensor)  # [N_patches, 384]
        
        # ④ 像素灰度波动（DINOv2不直接保留，需传统方法补充）
        local_mean = cv2.boxFilter(gray, cv2.CV_64F, (16,16))
        local_std = local_std_filter(gray, (16,16))
        gray_stats = np.stack([local_mean, local_std], axis=-1)
        
        # ② 边缘连续性（可解释性增强）
        edges = cv2.Canny(gray, 50, 150)
        
        return {
            'semantic': dino_feat,      # ①②③⑤ 语义特征
            'gray_stats': gray_stats,    # ④ 灰度统计
            'edges': edges,              # ② 边缘（可解释）
        }
    
    def anomaly_score(self, features, normal_memory):
        """融合五类特征计算异常分数"""
        # DINOv2 特征：最近邻距离（编码①②③⑤）
        dino_dist = knn_distance(features['semantic'], normal_memory['semantic'])
        
        # 灰度统计：偏离正常范围（编码④）
        gray_dist = np.abs(features['gray_stats'] - normal_memory['gray_stats_mean'])
        
        # 边缘：连通性异常（编码②）
        edge_anomaly = edge_breakness(features['edges'])
        
        # 加权融合
        score = 0.6 * dino_dist + 0.25 * gray_dist + 0.15 * edge_anomaly
        return score
```

### 五类特征与检测方法的映射

| 特征类 | 最佳检测方法 | 异常类型 |
|--------|------------|---------|
| ① 纹理排布 | DINOv2 patch 特征 + PCA/Dinomaly | 划痕、污渍、腐蚀 |
| ② 边缘连续性 | DINOv2 + Canny 后处理 | 裂纹、断裂、错位 |
| ③ 反光光泽 | DINOv2 + 频域分析 | 凹坑、氧化、油污 |
| ④ 灰度波动 | 传统局部统计（补充DINOv2） | 黑斑、亮点、变色 |
| ⑤ 自相似性 | DINOv2 patch 间注意力 | 异物、缺料、变形 |

## 总结

### 对问题 1 的回答
> 多模态大模型 API **不能用于在线推理**（赛题要求 <200ms），但**可以用于离线训练**：用 Stable Diffusion 生成伪异常数据（扩充 30→3000 张），用 GPT-4V 验证质量+自动标注，然后用增强数据训练本地小模型。在线推理只用 DINOv2-S + 轻量检测头，不调 API。

### 对问题 2 的回答
> 五类通用底层视觉特征：① 局部纹理排布 ② 细小边缘连续性 ③ 材质反光光泽 ④ 像素灰度波动 ⑤ 区域自相似性。DINOv2 隐式编码了①②③⑤（因其 1.42 亿图自监督预训练），但④（像素灰度波动）这种低级统计在 ViT 高维语义特征中会被稀释，需用传统局部统计方法补充。最佳实践是 **DINOv2 语义特征 + 传统低级特征融合**。
