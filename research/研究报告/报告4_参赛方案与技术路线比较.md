# 报告四：可行参赛方案与技术路线比较

> 基于赛题要求、数据集特性与参考文献，本报告设计 4 条技术路线并比较优劣，给出推荐方案与实施路线图。

---

## 一、赛题需求拆解与技术挑战

### 1.1 需求-技术映射

| 赛题要求 | 量化指标 | 技术挑战 | 对应技术方向 |
|---------|---------|---------|------------|
| 实时检测 | 2500×2500, 2060 GPU, <200ms | 大图 + 低算力 + 低延迟 | 轻量模型 + 分块推理 |
| 少样本启动 | 100 正 + 30 异 | 极少异常样本 + 开放集 | OSAD / 少样本学习 |
| 泛化能力 | 1000+ 测试集含未知缺陷 | 训练缺陷≠测试缺陷 | 异质分布学习 |
| 反馈驱动优化 | 误检/漏检后可更新 | 在线适应 | 主动学习 / 增量学习 |
| 可解释性 | 文档 + 论据 | 决策可追溯 | 注意力可视化 / 热力图 |
| 评分导向 | 速度 18% > 准确率 12% | 速度优先 | 模型压缩 / 蒸馏 |

### 1.2 核心矛盾

```
矛盾 1：少样本(30异) vs 高泛化(未知缺陷)
矛盾 2：大输入(2500²) vs 低延迟(<200ms)  
矛盾 3：高准确率 vs 高速度（评分权重 12% vs 18%）
矛盾 4：图片+视频双模态 vs 轻量化
```

## 二、技术路线全景图

基于工业异常检测领域的方法谱系，梳理出 4 条可行路线：

```
                    ┌─ 路线A：无监督方法（PatchCore/EfficientAD）
                    │  优势：速度快、成熟   劣势：不用30张异常样本
                    │
  本赛题 ───────────┼─ 路线B：少样本/零样本 VLM（WinCLIP/PromptAD）
   100正+30异        │  优势：泛化强   劣势：速度慢、模型大
   开放集检测        │
                    ├─ 路线C：开放集监督 OSAD（AHL）⭐ 推荐
                    │  优势：最对口、用上30异   劣势：训练复杂
                    │
                    └─ 路线D：混合方案（AHL + 轻量主干 + 在线学习）
                       优势：全面   劣势：工程量大
```

## 三、路线 A：无监督异常检测方法

### 3.1 代表方法

| 方法 | 架构 | MVTec AD AUROC | 推理延迟 | 参数量 | 特点 |
|------|------|---------------|---------|--------|------|
| **EfficientAD** | Student-Teacher + AE | 99.1% | **2.2ms** | 2.4M | 速度之王 |
| **PatchCore** | 记忆库 + k-NN | 99.1% | 32ms | 105M | 精度强、免训练 |
| **FastFlow** | 归一化流 + CNN | 99.4% | 17ms | 25M | 平衡型 |
| **PaDiM** | 多元高斯 + 预训练 | 97.9% | <50ms | - | 简单、低延迟 |
| **DRAEM** | 重建 + 判别 | 98.0% | - | - | 重建类代表 |
| **Reverse Distillation** | Student-Teacher 反向 | 98.5% | - | - | 蒸馏类代表 |

### 3.2 方案设计（以 EfficientAD 为例）

```
输入 2500×2500 图
    │
    ├─ 分块：切分为 25 个 512×512 子块（或下采样到 1024）
    │
    ▼
[PDN 轻量特征提取器] (Patch Description Network, ~2M参数)
    │
    ├─ Student 网络：模仿 Teacher
    ├─ AutoEncoder：重建特征
    │
    ▼
异常分数 = Student-Teacher 差异 + AE 重建误差
    │
    ▼
分块结果融合 → 图像级异常分数 + 像素级热力图
```

### 3.3 优劣分析

| 维度 | 评价 | 说明 |
|------|------|------|
| ✅ 速度 | 极优 | EfficientAD 延迟 2.2ms，远低于 200ms |
| ✅ 成熟度 | 极优 | 工业落地最多，代码完善 |
| ⚠️ 准确率 | 中 | 不利用 30 张异常样本，信息浪费 |
| ❌ 范式匹配 | 差 | 赛题给了异常样本却不用，"答非所问" |
| ✅ 简单性 | 优 | 训练简单，仅需正常样本 |
| ⚠️ 创新性 | 低 | 专家评分可能不高 |

### 3.4 适用场景
- 作为**基线方案**快速跑通流程
- 作为**预训练特征提取器**供其他路线使用
- 速度分（18%）要求极高时的保底方案

## 四、路线 B：少样本/零样本视觉语言模型

### 4.1 代表方法

| 方法 | 类型 | 1-shot AUROC | 4-shot AUROC | 模型规模 | 特点 |
|------|------|-------------|-------------|---------|------|
| **WinCLIP** | 零样本/少样本 | 93.1% | 95.2% | CLIP-Large | 免训练、文本提示 |
| **PromptAD** | 少样本提示学习 | 94.6% | 96.6% | CLIP | 正常样本学提示 |
| **APRIL-GAN** | 零样本 | 92.0% | 92.8% | CLIP | VAND 竞赛冠军 |
| **AnomalyGPT** | 大视觉语言模型 | 94.1% | 96.3% | LLM+VLM | 可解释、对话式 |
| **UniVAD** | 免训练统一 | - | - | 预训练 | CVPR 2025 |
| **VisionAD** | 检索式 | 97.4% | 98.6% | - | SOTA 少样本 |

### 4.2 方案设计（以 PromptAD 为例）

```
训练阶段：
  100 张正常图片 + CLIP 视觉编码器
    → 学习"正常"的可学习提示词（prompt tokens）
    → 文本端：[正常提示] vs [异常提示]

推理阶段：
  测试图 → CLIP 编码 → 与正常/异常提示计算相似度
    → 异常分数 = sim(图像, 异常提示) - sim(图像, 正常提示)
```

### 4.3 优劣分析

| 维度 | 评价 | 说明 |
|------|------|------|
| ✅ 泛化能力 | 极优 | CLIP 预训练知识强，零样本也能检测 |
| ✅ 少样本友好 | 优 | 1-4 张即可 |
| ⚠️ 30 张异常利用 | 中 | 部分方法（PromptAD）只用正常样本 |
| ❌ 速度 | 差 | CLIP-Large 推理慢，2500×2500 难达标 |
| ❌ 模型大小 | 差 | 大模型，2060 显存紧张 |
| ✅ 可解释性 | 优 | AnomalyGPT 可输出文本解释 |
| ✅ 创新性 | 优 | VLM 是前沿方向 |

### 4.4 适用场景
- 对泛化能力要求极高的场景
- 作为**辅助方案**提供可解释性
- 速度要求放宽时的备选

## 五、路线 C：开放集监督异常检测（AHL）⭐ 推荐

### 5.1 代表方法

| 方法 | 类型 | MVTec AD AUROC | 特点 | 与赛题匹配度 |
|------|------|---------------|------|------------|
| **DevNet** | OSAD | 94.8% | 偏差网络，开创 OSAD | 高 |
| **DRA** | OSAD | 96.6% | 解纠缠表示 | 高 |
| **AHL(DevNet)** | OSAD+异质学习 | 95.4% | 即插即用增强 | **极高** |
| **AHL(DRA)** | OSAD+异质学习 | **97.0%** | 最强 OSAD | **极高** |
| BGAD | OSAD | - | 归一化流边界 | 高 |

### 5.2 方案设计（AHL + 轻量化改造）

```
═══════════════════════════════════════════════════════
  训练阶段（离线，用公开数据集）
═══════════════════════════════════════════════════════

输入：100 正 + 30 异（模拟赛题协议）
  │
  ├─【特征提取】用预训练轻量网络（如 ResNet18 / MobileNetV3）
  │   而非原 AHL 的 ResNet38，降低参数量
  │
  ├─【HADG 异质分布生成】
  │   ① 正常样本 k-means 聚类 C=3 簇
  │   ② 生成 T=5 个异质数据集（降低 T 以减少训练成本）
  │   ③ 伪异常：CutPaste + DRAEM Mask
  │
  ├─【CDL 协作学习】
  │   ① 5 个轻量基础模型 + 1 个统一模型
  │   ② 交替优化（偏差损失）
  │   ③ 自监督序列模型评估权重
  │
  └─ 输出：统一模型 g（轻量，满足推理需求）

═══════════════════════════════════════════════════════
  推理阶段（在线，赛题测试）
═══════════════════════════════════════════════════════

输入 2500×2500 图
  │
  ├─ 分块：切分为 512×512 子块（滑窗，重叠 64px）
  │
  ├─ 各子块 → 统一模型 g → 异常分数
  │
  ├─ 融合：取 max / 加权平均 → 图像级分数
  │
  └─ 输出：异常/正常 + 像素级热力图（可解释性）
```

### 5.3 关键改造点

| 原版 AHL | 赛题改造 | 理由 |
|---------|---------|------|
| ResNet38 特征 | ResNet18 / MobileNetV3 | 满足 <200ms |
| T=7 基础模型 | T=5 | 降低训练成本 |
| 256×256 输入 | 分块 512×512 | 适应 2500×2500 |
| 仅图片 | + 视频抽帧 | 支持视频模态 |
| 无在线学习 | + 主动学习模块 | 反馈驱动优化 |

### 5.4 优劣分析

| 维度 | 评价 | 说明 |
|------|------|------|
| ✅ 范式匹配 | 极优 | OSAD = 赛题设定，完美对口 |
| ✅ 异常样本利用 | 极优 | 充分用 30 张异常 |
| ✅ 泛化能力 | 优 | 异质分布学习应对未知缺陷 |
| ✅ 准确率 | 优 | MVTec AD 97% AUC |
| ⚠️ 速度 | 中 | 需轻量化改造才能达标 |
| ✅ 创新性 | 极优 | CVPR 2024 + 改造，故事性强 |
| ⚠️ 复杂度 | 中高 | 训练 T 个模型，工程量大 |
| ✅ 可解释性 | 优 | 异常分数 + 热力图 |

### 5.5 为什么推荐 AHL

1. **范式完美对口**：AHL 研究的 OSAD = 赛题的"100 正 + 30 异检测未知缺陷"
2. **充分利用异常样本**：30 张异常样本是赛题给的"先验知识"，不用就浪费了
3. **泛化能力强**：异质分布学习专门解决"未知缺陷"问题
4. **即插即用**：可换轻量主干满足速度要求
5. **创新故事好**：基于 CVPR 2024 前沿工作 + 工程改造，专家评分高
6. **有官方代码**：https://github.com/mala-lab/AHL 可直接复现

## 六、路线 D：混合方案（推荐最终方案）

### 6.1 设计理念

结合各路线优势，构建**端到端参赛系统**：

```
路线A (EfficientAD) ─┐
                      ├─→ 混合方案 D
路线C (AHL) ─────────┘     + 在线学习 + 可解释性
```

### 6.2 系统架构

```
┌────────────────────────────────────────────────────────────┐
│                   参赛系统架构（路线D）                        │
│                                                            │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐ │
│  │  输入预处理   │───→│  检测核心     │───→│  后处理+输出  │ │
│  │              │    │              │    │              │ │
│  │ • 图片/视频  │    │ Level-1:     │    │ • 分数融合    │ │
│  │   抽帧       │    │  EfficientAD │    │ • 热力图生成  │ │
│  │ • 2500→分块  │    │  快速初筛     │    │ • 可解释报告  │ │
│  │   512×512    │    │  (<10ms)     │    │              │ │
│  │              │    │      ↓       │    │              │ │
│  │              │    │ Level-2:     │    │              │ │
│  │              │    │  AHL(DRA)    │    │              │ │
│  │              │    │  精细判定     │    │              │ │
│  │              │    │  (仅可疑块)  │    │              │ │
│  └──────────────┘    └──────────────┘    └──────────────┘ │
│                                                            │
│  ┌──────────────────────────────────────────────────────┐ │
│  │              在线学习闭环（反馈驱动）                   │ │
│  │  操作员标记误检/漏检 → 主动学习选样 → 增量更新模型     │ │
│  └──────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

### 6.3 两级级联检测（核心创新）

**Level-1 快速初筛（EfficientAD）**：
- 所有子块过一遍，延迟 <10ms/块
- 输出初步异常分数
- **阈值过滤**：分数 < τ_low 直接判正常

**Level-2 精细判定（AHL）**：
- 仅对 Level-1 标记的可疑块（分数 > τ_low）精细检测
- 利用 30 张异常样本的先验知识
- 输出精确异常分数 + 热力图

**优势**：
- 大部分正常块在 Level-1 就过滤掉，无需过 AHL → **整体速度接近 EfficientAD**
- 可疑块用 AHL 精细判定 → **准确率接近 AHL**
- 兼顾速度（18%）和准确率（12%）

### 6.4 在线学习闭环设计

```
┌─ 推理输出 ─────────────────────────────────────────────┐
│  检测结果 → 操作员审核                                  │
│    ├─ 正确：无需操作                                    │
│    ├─ 误检（假阳性）：标记"这是正常的"                   │
│    └─ 漏检（假阴性）：标记"这里有缺陷" + 框选区域        │
└────────────────────────────────────────────────────────┘
          │
          ▼
┌─ 主动学习选样 ─────────────────────────────────────────┐
│  ① 不确定性采样：选模型最没把握的样本（分数接近阈值）     │
│  ② 多样性采样：确保选出的样本覆盖不同缺陷类型            │
│  ③ 委员会查询：多个基础模型分歧大的样本优先              │
└────────────────────────────────────────────────────────┘
          │
          ▼
┌─ 增量更新 ─────────────────────────────────────────────┐
│  ① 将反馈样本加入训练集                                 │
│  ② 对统一模型 g 做少量 epoch 微调（而非重训）           │
│  ③ 定期全量重训（离线，不影响在线推理）                  │
└────────────────────────────────────────────────────────┘
```

### 6.5 视频模态处理

```
视频输入
  │
  ├─ 关键帧抽取（每 N 帧取 1 帧，或场景变化检测）
  │   降低时序冗余
  │
  ├─ 单帧检测（用上述图片检测管线）
  │
  ├─ 时序融合（可选）：
  │   • 滑动窗口投票（多数表决）
  │   • 轻量 3D 卷积（时空特征）
  │   • 时序一致性约束（连续帧结果应平滑）
  │
  └─ 输出：视频级异常时间戳 + 帧级热力图
```

### 6.6 可解释性设计

| 可解释维度 | 实现方式 |
|-----------|---------|
| **异常定位** | 像素级热力图，高亮缺陷区域 |
| **异常评分** | 数值化分数 + 阈值解释 |
| **决策依据** | Level-1/Level-2 分数对比 |
| **缺陷类型** | 与训练异常的相似度匹配 |
| **置信度** | 基于基础模型一致性 |
| **对比展示** | 正常参考图 vs 测试图差异图 |

## 八、实施路线图

### 8.1 分阶段计划

```
阶段 1：基线搭建（第1-2周）
├── 复现 EfficientAD，跑通 MVTec AD
├── 实现分块推理管线（2500→512 子块）
├── 验证 <200ms 延迟目标
└── 交付：速度基线 + 检测 demo

阶段 2：AHL 集成（第3-4周）
├── 复现 AHL 代码（github.com/mala-lab/AHL）
├── 改造为轻量主干（ResNet18）
├── 模拟赛题协议：100正+30异 训练验证
├── 在 MVTec AD 15 类上验证泛化
```

## 十、总结与最终建议

### 10.1 一句话方案

> **以 AHL（CVPR 2024 开放集监督异常检测）为核心算法，前置 EfficientAD 做快速初筛构成级联检测，辅以主动学习实现反馈驱动的在线优化，用分块推理适配 2500×2500 大图，用抽帧策略支持视频模态，最终形成一套兼顾速度（18%）、准确率（12%）、完整度（30%）和创新性（40%）的端到端 AOI 质检系统。**

### 10.2 核心竞争力

1. **范式对口**：AHL 的 OSAD = 赛题设定，比无监督/VLM 更贴合
2. **速度-精度平衡**：级联设计，速度接近 EfficientAD，精度接近 AHL
3. **数据利用充分**：100 正 + 30 异 全部用上，不浪费先验知识
4. **系统完整**：检测 + 反馈 + 在线学习 + 可解释，覆盖赛题全部要求
5. **创新故事**：CVPR 2024 前沿 + 工程级联创新，专家评分有亮点

### 10.3 关键提醒

- ⚠️ **速度优先**：评分中速度（18%）> 准确率（12%），不要为精度牺牲速度
- ⚠️ **文档为重**：方案完整度（30%）+ 专家（40%）= 70%，文档质量决定成败
- ⚠️ **严格模拟**：用公开数据集严格按 100+30 协议验证，不要作弊看测试集
- ⚠️ **小模型鼓励**：赛题明确鼓励小模型，与级联设计理念一致
