# 补充报告：EfficientAD 是否最佳？2023-2026 全方法对比（速度优先）

> 优先级：**速度第一，精度第二**（对应赛题评分：速度 18% > 准确率 12%）
> 硬件约束：RTX 2060 GPU，2500×2500 输入，<200ms

---

## 一、直接回答

**EfficientAD 在"纯速度"维度仍是 2060 级硬件上的最佳选择，但它不是精度最优。** 2025-2026 出现了多个精度更高的方法，但它们依赖重量级骨干网络（DINOv2/Transformer/扩散模型），在 2060 上跑 2500×2500 难以满足 <200ms。

**关键发现**：可以用 **EfficientAD 的轻量 PDN 特征 + SubspaceAD 的 PCA 子空间建模** 组合出一个又快又准的新方案——这是本赛题的一个创新点。

## 三、2026 年三大新方法详解

### 3.1 SubspaceAD（CVPR 2026）⭐ 赛题高度相关

| 维度 | 详情 |
|------|------|
| **核心思想** | 冻结 DINOv2 提特征 + PCA 拟合正常子空间 + 重建残差 = 异常分数 |
| **最大卖点** | **免训练**！1 张正常图即可部署，PCA 拟合秒级完成 |
| **精度** | 1-shot: MVTec AD 98.0% / VisA 93.3%（少样本 SOTA） |
| **速度** | 672×672 在 H100 上 ~300ms（DINOv2 占 270ms，PCA 仅 30ms） |
| **存储** | 每品类 <1MB（仅均值 μ + 基矩阵 C） |
| **代码** | https://github.com/CLendering/SubspaceAD |
| **赛题匹配** | 少样本设定（100正）完美匹配，但 DINOv2-G 太重，2060 上不达标 |

**关键启发**：PCA 子空间建模极其轻量（30ms），瓶颈在 DINOv2。如果**换成 EfficientAD 的 PDN 特征做 PCA**，速度问题可解决！

### 3.2 InvAD（CVPR 2026）

| 维度 | 详情 |
|------|------|
| **核心思想** | 扩散模型反演范式：不重建，直接在隐空间反演 3 步测异常 |
| **最大卖点** | 88 FPS（~11ms），扩散类方法中最快，精度 99.0% |
| **精度** | MVTec AD 99.0%（图像级 SOTA 之一） |
| **速度** | 4090 上 88 FPS，仅 3 步反演（vs 传统扩散几十步） |
| **范式** | 无监督（仅正常样本训练），多类统一 |
| **赛题匹配** | 速度尚可，但不利用 30 张异常样本；扩散训练复杂 |

### 3.3 UniMMAD（CVPR 2026）

| 维度 | 详情 |
|------|------|
| **核心思想** | 混合专家(MoE)统一多模态多类异常检测 |
| **最大卖点** | 59 FPS，支持 RGB/3D/红外多模态，持续学习不遗忘 |
| **精度** | MVTec-3D 92.5%（多模态场景） |
| **赛题匹配** | 过于复杂，多模态非赛题必需 |

## 四、按赛题约束的可行性分级

赛题约束：**RTX 2060（6GB显存）+ 2500×2500 + <200ms**

### 4.1 分块推理的延迟估算

2500×2500 切成 512×512 子块约需 25 块。设单块推理延迟为 t：

| 方案 | 单块 t(ms,2060估算) | 25块总延迟 | 是否<200ms |
|------|---------------------|-----------|-----------|
| EfficientAD-S | ~5-8 | 125-200 | ✅ 勉强/可行 |
| EfficientAD-M | ~10-15 | 250-375 | ⚠️ 需优化 |
| InvAD | ~25-40 | 625-1000 | ❌ 不行 |
| SimpleNet | ~30-50 | 750-1250 | ❌ 不行 |
| SubspaceAD(DINOv2-G) | ~600+ | 15000+ | ❌ 完全不行 |
| INP-Former | ~90+ | 2250+ | ❌ 不行 |

> 注：2060 约为 A6000 性能的 1/3-1/4，上述为粗略估算。实际可用并行批处理、下采样、稀疏推理优化。

### 4.2 可行性分级

| 级别 | 方法 | 说明 |
|------|------|------|
| ✅ **直接可用** | EfficientAD-S | 唯一能在 2060 上跑 2500×2500 且 <200ms 的 |
| ⚠️ **需优化** | EfficientAD-M, InvAD | 需降分辨率/减少分块/批处理优化 |
| ❌ **不可用**（速度） | SimpleNet, PatchCore, INP-Former, SubspaceAD, Dinomaly | 骨干太重，2060 上无法满足 <200ms |

## 五、速度优先下的最佳策略

### 5.1 核心矛盾

```
速度王者(EfficientAD) ≠ 精度王者(INP-Former/Dinomaly)
精度王者 ≠ 少样本王者(SubspaceAD/AHL)
少样本王者(AHL) ≠ 速度王者

→ 没有单一方法同时满足"最快+最准+少样本+2060"
→ 必须用级联/组合策略
```

### 5.2 推荐组合方案（更新版）

基于新调研，提出**三层级联 + 创新融合**方案：

```
┌──────────────────────────────────────────────────────────┐
│  Level-1: 快速初筛 — EfficientAD-S (PDN, ~5ms/块)        │
│  • 过滤 90%+ 正常块                                       │
│  • 速度分(18%)的保障                                      │
├──────────────────────────────────────────────────────────┤
│  Level-2: 精细判定 — AHL(DRA) 轻量化版                   │
│  • 仅对可疑块推理，用 30 张异常先验                       │
│  • 准确率分(12%)的保障                                    │
├──────────────────────────────────────────────────────────┤
│  创新融合: PDN特征 + PCA子空间建模 (借鉴 SubspaceAD)      │
│  • 用 EfficientAD 的 PDN 提特征                           │
│  • 用 SubspaceAD 的 PCA 拟合正常子空间                    │
│  • 免训练、<1MB存储、PCA仅30ms                            │
│  • 作为 Level-1 的增强或 Level-0 快速通道                 │
└──────────────────────────────────────────────────────────┘
```

### 5.3 创新点：PDN-PCA 融合方案

这是基于 2026 年 SubspaceAD 启发的新组合，可作为赛题的**创新亮点**：

| 组件 | 来源 | 作用 |
|------|------|------|
| 特征提取 | EfficientAD 的 PDN（4层CNN, 0.7M参数） | 极快提特征，~1ms |
| 正常建模 | SubspaceAD 的 PCA 子空间（借鉴） | 免训练拟合正常分布，~1ms |
| 异常评分 | 重建残差 ‖x - proj(x)‖² | 统计可解释 |

**优势**：
- 速度：PDN(1ms) + PCA(1ms) ≈ 2ms/块，25块 ≈ 50ms → **远低于 200ms**
- 精度：PCA 子空间在强特征上表现优异（SubspaceAD 已验证）
- 创新：首次将 PDN 轻量特征与 PCA 子空间结合，有发表价值
- 可解释：残差有明确统计意义，满足赛题可解释性要求

### 6.2 关键结论

1. **EfficientAD 仍是 2060 上速度最优选择**——其 PDN（0.7M参数）是所有方法中最轻的，2026 年新方法虽精度更高但骨干太重
2. **2026 年精度 SOTA 是 INP-Former(99.9%) 和 Dinomaly(99.8%)**，但在 2060 上无法满足 <200ms
3. **SubspaceAD 的 PCA 思想极具价值**——免训练、少样本、可解释，但其 DINOv2 骨干不可用，**可借鉴其 PCA 部分嫁接到 PDN 特征上**
4. **InvAD 是扩散类中速度最快的**(88FPS)，但扩散训练复杂且不利用异常样本，非最优
5. **最佳策略仍是级联**：EfficientAD 保速度 + AHL 保精度 + PDN-PCA 融合做创新点

## 七、总结

> **EfficientAD 在"2060 + <200ms"的硬约束下仍是速度最佳选择，没有 2025-2026 的方法能在该硬件上取代它的速度优势。** 但精度上已被 INP-Former(99.9%)、Dinomaly(99.8%) 超越。最佳策略不是换掉 EfficientAD，而是**用它做初筛 + AHL 做精判 + 借鉴 SubspaceAD 的 PCA 思想做创新融合**，同时拿下速度分(18%)、准确率分(12%)和专家创新分(40%)。
