## 二、DAGM 2007 数据集详解

### 2.1 数据集背景

DAGM 2007 是 2007 年德国模式识别工作组（DAGM） symposium 上举办的**弱监督工业光学检测竞赛**数据集，由 Matthias Wieler 和 Tobias Hahn 在 Robert Bosch 企业研究部创建。

**竞赛原始要求**（与本赛题高度相关）：
- 检测各种纹理背景上的多种缺陷
- 从**弱标签**训练数据中自动学习
- 数据特征在开发时**未知**
- 所有参数**自动适配**，无需人工干预
- 适度运行时间（竞赛要求训练 24h + 测试 12h）
- 考虑**非对称代价**：假阳性和假阴性代价比为 1:20

### 2.2 数据集结构

#### 10 个子集划分

```
DAGM 2007/
├── 开发数据集（6 个，用于算法开发）
│   ├── Class1/  ~1150 张
│   ├── Class2/  ~1150 张
│   ├── Class3/  ~1150 张
│   ├── Class4/  ~1150 张
│   ├── Class5/  ~1150 张
│   └── Class6/  ~1150 张
│
└── 竞赛数据集（4 个，用于性能评估）
    ├── Class7/   ~2300 张
    ├── Class8/   ~2300 张
    ├── Class9/   ~2300 张
    └── Class10/  ~2300 张
```

#### 每个子集的规模

| 数据集类型 | 无缺陷图像 | 有缺陷图像 | 总计 |
|-----------|-----------|-----------|------|
| 开发集（Class 1-6） | 1000 张 | 150 张 | 1150 张 |
| 竞赛集（Class 7-10） | 2000 张 | 300 张 | 2300 张 |

#### 单个子集的目录结构

```
Class1/
├── Class1/
│   ├── 001.PNG          # 原始图像（灰度 8-bit）
│   ├── 002.PNG
│   ├── ...
│   └── 1150.PNG
│
└── Class1_label/
    ├── Label/
    │   ├── 001_label.PNG   # 标签图像（缺陷区域掩码）
    │   ├── 002_label.PNG
    │   └── ...
    │   └── Labels.txt       # 元数据 ASCII 文本文件
    │
    └── (无缺陷图像无对应 label 文件)
```

### 2.3 标注格式

#### 弱标签（椭圆标注）

- 标签以**椭圆**形式粗略标注缺陷区域
- 标签图像为单独的灰度 8-bit PNG，位于 `Label` 文件夹
- 像素值：**0 = 背景，255 = 缺陷区域**

#### Labels.txt 结构

```
1
[id_1] \t [0或1] \t [原始图像文件名] \t 0 \t [标签图像文件名或0] 
[id_2] \t [0或1] \t [原始图像文件名] \t 0 \t [标签图像文件名或0]
...
[id_N] \t [0或1] \t [原始图像文件名] \t 0 \t [标签图像文件名或0]
```

**字段说明**：
- 第 1 行：数据总数 N
- 第 1 列：样本 ID
- 第 2 列：`0` = 无缺陷，`1` = 有缺陷
- 第 3 列：原始图像文件名
- 第 4 列：固定为 `0`
- 第 5 列：标签图像文件名（无缺陷时为 `0`）

**示例**：
```
1150
1	0	001.PNG	0	0
2	1	002.PNG	0	002_label.PNG
3	0	003.PNG	0	0
...
```

### 2.4 数据特点

- **人工合成但接近真实**：由不同的纹理模型和缺陷模型生成
- **每个子集不同**：纹理和缺陷模式各异
- **单缺陷**：每张缺陷图恰好有**一个**标注缺陷
- **已划分训练/测试**：每个子集随机等分为训练集和测试集
- **非对称代价**：假阴性（漏检）代价是假阳性（误检）的 20 倍 → **召回率优先**

### 2.5 下载方式

- **官网**：https://hci.iwr.uni-heidelberg.de/node/3616（即数据集文件夹中的 URL）
- **方式**：填写表单，下载链接发送至邮箱
- **许可**：CC BY 4.0（可自由使用，需署名）
- **引用格式**：
  > Matthias Wieler, Tobias Hahn, Fred. A. Hamprecht. (2007) Weakly supervised learning for industrial optical inspection. [Dataset].

## 三、MVTec AD 数据集详解

### 3.1 数据集背景

MVTec AD 是工业异常检测领域**最权威的基准数据集**，专为评测无监督异常检测方法设计。训练集仅包含正常图像，测试集包含各类缺陷图像及像素级精确标注。

- **论文**：《The MVTec Anomaly Detection Dataset: A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection》(IJCV 2021)
- **总图像**：5,354 张
- **异常区域**：1,888 个精确标注
- **缺陷类型**：73 种

### 3.2 15 个类别详情

- **照明**：高度控制（部分类别故意改变照明增加变异性）
- **裁剪后分辨率**：700×700 ~ 1024×1024
- **灰度类别**：grid、screw、zipper 为单通道灰度
- **每图唯一样本**：无数据增强，每张图显示不同物理样本

## 四、两个数据集与本赛题的适配分析

### 4.1 赛题评测协议回顾

```
训练：100 张无缺陷 + 30 张有缺陷  →  测试：1000+ 张
```

### 4.2 DAGM 2007 的适配性

| 维度 | DAGM 2007 | 赛题要求 | 适配度 |
|------|-----------|---------|--------|
| 学习范式 | 弱监督（有缺陷样本+弱标签） | 少样本监督（有 30 张缺陷） | ✅ 高度匹配 |
| 缺陷样本 | 每子集 150-300 张缺陷 | 30 张 | ✅ 可下采样模拟 |
| 标注粒度 | 椭圆区域（弱标签） | 检测异常 | ✅ 适配 |
| 分辨率 | 512×512 | 2500×2500 | ⚠️ 偏小，需考虑尺寸策略 |
| 模态 | 灰度图片 | 图片+视频 | ⚠️ 仅图片、仅灰度 |
| 非对称代价 | 1:20（漏检代价高） | 未明确但工业场景同 | ✅ 启发召回优先 |

**结论**：DAGM 2007 的**弱监督设定与赛题的少样本监督设定高度吻合**，是模拟赛题评测协议的首选。

### 4.3 MVTec AD 的适配性

| 维度 | MVTec AD | 赛题要求 | 适配度 |
|------|----------|---------|--------|
| 学习范式 | 无监督（训练仅正常） | 少样本监督（有 30 张缺陷） | ⚠️ 需改造为半监督 |
| 缺陷样本 | 测试集中有 | 30 张用于训练 | ✅ 可提取部分缺陷做训练 |
| 标注粒度 | 像素级精确 | 检测异常 | ✅ 优秀 |
| 分辨率 | 1024×1024 | 2500×2500 | ⚠️ 偏小 |
| 模态 | RGB 图片 | 图片+视频 | ⚠️ 仅图片 |
| 类别多样性 | 15 类，工业场景丰富 | 多组件 | ✅ 适配 |
| 缺陷类型 | 73 种，覆盖广 | 尺寸/缺件/逻辑/色彩/外观 | ✅ 高度适配 |

**结论**：MVTec AD 是**最权威的工业异常检测基准**，类别丰富、标注精确，适合验证模型泛化能力。但其原始设定是无监督，需改造为"100 正 + 30 异"的协议。

### 4.4 推荐使用策略

```
┌──────────────────────────────────────────────────────┐
│  阶段 1：方法开发（用 DAGM 开发集 Class1-6）           │
│  ├── 验证少样本监督学习管线                            │
│  └── 调试 100+30 协议                                │
│                                                      │
│  阶段 2：泛化验证（用 MVTec AD 全 15 类）              │
│  ├── 验证跨类别泛化能力                               │
│  ├── 模拟赛题协议：每类取 100 正 + 30 异训练           │
│  └── 测试集评估                                       │
│                                                      │
│  阶段 3：最终验证（用 DAGM 竞赛集 Class7-10）          │
```

## 五、数据加载与预处理代码示例

### 5.1 MVTec AD 数据加载（PyTorch）

```python
import os
import numpy as np
from PIL import Image
import torch
from torch.utils.data import Dataset, DataLoader

class MVTecDataset(Dataset):
    """MVTec AD 数据集加载器"""
    
    def __init__(self, root, category, split='train', transform=None):
        """
        Args:
            root: 数据集根目录
            category: 类别名，如 'bottle', 'carpet'
            split: 'train' 或 'test'
            transform: 数据增强
        """
        self.root = root
        self.category = category
        self.split = split
        self.transform = transform
        
        self.img_dir = os.path.join(root, category, split)
        self.gt_dir = os.path.join(root, category, 'ground_truth')
        
        self.samples = []
        if split == 'train':
            # 训练集只有 good 文件夹
            good_dir = os.path.join(self.img_dir, 'good')
            for fname in sorted(os.listdir(good_dir)):
                self.samples.append({
                    'img_path': os.path.join(good_dir, fname),
                    'gt_path': None,
                    'label': 0,  # 0=正常
                    'defect_type': 'good'
                })
        else:
            # 测试集包含多个缺陷类型子文件夹
            for defect_type in os.listdir(self.img_dir):
                defect_dir = os.path.join(self.img_dir, defect_type)
                if not os.path.isdir(defect_dir):
                    continue
                for fname in sorted(os.listdir(defect_dir)):
                    if not fname.endswith('.png'):
                        continue
                    gt_path = None
                    label = 0
                    if defect_type != 'good':
                        label = 1
                        gt_name = fname.replace('.png', '_mask.png')
                        gt_path = os.path.join(self.gt_dir, defect_type, gt_name)
                    self.samples.append({
                        'img_path': os.path.join(defect_dir, fname),
                        'gt_path': gt_path,
                        'label': label,
                        'defect_type': defect_type
                    })
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        sample = self.samples[idx]
        img = Image.open(sample['img_path']).convert('RGB')
        
        gt = None
        if sample['gt_path'] and os.path.exists(sample['gt_path']):
            gt = Image.open(sample['gt_path']).convert('L')
        
        if self.transform:
            img = self.transform(img)
            if gt is not None:
                gt = self.transform(gt)
        
        return {
            'image': img,
            'mask': gt,
            'label': sample['label'],
            'defect_type': sample['defect_type']
        }


# 模拟赛题协议：100 正常 + 30 异常
def build_competition_protocol(dataset, n_normal=100, n_anomaly=30, seed=42):
    """构建赛题的少样本训练协议"""
    normal_samples = [s for s in dataset.samples if s['label'] == 0]
    anomaly_samples = [s for s in dataset.samples if s['label'] == 1]
    
    rng = np.random.RandomState(seed)
    rng.shuffle(normal_samples)
    rng.shuffle(anomaly_samples)
    
    train_normal = normal_samples[:n_normal]
    train_anomaly = anomaly_samples[:n_anomaly]
    test_set = normal_samples[n_normal:] + anomaly_samples[n_anomaly:]
    
    return train_normal + train_anomaly, test_set
```

### 5.2 DAGM 2007 数据加载

```python
class DAGMDataset(Dataset):
    """DAGM 2007 数据集加载器"""
    
    def __init__(self, root, cls_idx=1, split='train', transform=None):
        """
        Args:
            root: DAGM 根目录
            cls_idx: 类别编号 1-10
            split: 'train' 或 'test'
        """
        cls_name = f'Class{cls_idx}'
        self.img_dir = os.path.join(root, cls_name, cls_name)
        self.label_dir = os.path.join(root, cls_name, f'{cls_name}_label', 'Label')
        self.transform = transform
        
        # 解析 Labels.txt
        labels_file = os.path.join(self.label_dir, 'Labels.txt')
        self.samples = []
        with open(labels_file, 'r') as f:
            lines = f.readlines()
        n_total = int(lines[0].strip())
        for line in lines[1:1+n_total]:
            parts = line.strip().split('\t')
            sample_id = int(parts[0])
            is_defective = int(parts[1]) == 1
            img_name = parts[2]
            label_name = parts[4] if is_defective else None
            
            self.samples.append({
                'img_path': os.path.join(self.img_dir, img_name),
                'label_path': os.path.join(self.label_dir, label_name) if label_name else None,
                'label': 1 if is_defective else 0,
            })
        
        # DAGM 已预先划分 train/test（等分）
        mid = len(self.samples) // 2
        self.samples = self.samples[:mid] if split == 'train' else self.samples[mid:]
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        sample = self.samples[idx]
        img = Image.open(sample['img_path']).convert('L')  # 灰度
        mask = None
        if sample['label_path']:
            mask = Image.open(sample['label_path']).convert('L')
        if self.transform:
            img = self.transform(img)
            if mask is not None:
                mask = self.transform(mask)
        return {'image': img, 'mask': mask, 'label': sample['label']}
```

### 5.3 评估指标计算

```python
from sklearn.metrics import roc_auc_score, average_precision_score

def evaluate_image_level(scores, labels):
    """图像级评估（分类：正常/异常）"""
    auroc = roc_auc_score(labels, scores)
    ap = average_precision_score(labels, scores)
    return {'image_AUROC': auroc, 'image_AP': ap}

def evaluate_pixel_level(score_maps, gt_masks):
    """像素级评估（定位：缺陷区域）"""
    # score_maps: [N, H, W], gt_masks: [N, H, W]
    all_scores = np.concatenate([s.flatten() for s in score_maps])
    all_masks = np.concatenate([m.flatten() for m in gt_masks])
    pixel_auroc = roc_auc_score(all_masks, all_scores)
    return {'pixel_AUROC': pixel_auroc}

def compute_pro(score_maps, gt_masks, threshold_step=0.01):
    """PRO (Per-Region Overlap) 指标"""
    # 对每个连通区域计算 IoU，更敏感于小缺陷
    from scipy.ndimage import label as cc_label
    pro_scores = []
    for threshold in np.arange(0, 1, threshold_step):
        overlaps = []
        for smap, gmask in zip(score_maps, gt_masks):
            binary_pred = (smap >= threshold).astype(np.uint8)
            labeled, n_regions = cc_label(gmask)
            for region_id in range(1, n_regions + 1):
                region = (labeled == region_id)
                overlap = (binary_pred & region).sum() / region.sum()
                overlaps.append(overlap)
        pro_scores.append(np.mean(overlaps))
    # PRO = PRO 曲线下面积
    return np.trapz(pro_scores, dx=threshold_step)
```

## 六、关键注意事项

### 6.1 DAGM 2007 使用注意

1. **代码荣誉**：开发完成前不要使用竞赛集（Class7-10）
2. **弱标签性质**：椭圆标注是粗略的，不能作为像素级 GT
3. **非对称代价**：评估时应重视召回率（漏检代价 20 倍）
4. **灰度图像**：需调整模型输入通道（1 通道 vs 3 通道）

### 6.2 MVTec AD 使用注意

1. **非商用许可**：CC BY-NC-SA 4.0，仅限研究用途
2. **无监督设定**：原始设计训练集只有正常图像，赛题需改造为半监督
3. **灰度类别**：grid/screw/zipper 为灰度，需统一处理
4. **分辨率不一**：capsule 为 1000×1000，其余多为 1024×1024

### 6.3 与赛题 2500×2500 的差距

两个数据集分辨率（512 / 1024）均小于赛题的 2500×2500。应对策略：

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| **分块推理** | 将大图切分为 512×512 子块，分别检测 | 通用，推荐 |
| **特征金字塔** | 多尺度特征提取 | 需要全局上下文时 |
| **下采样** | 整体缩放至 1024 后检测 | 缺陷较大时可行 |
| **滑窗 + 融合** | 滑窗检测 + 结果融合 | 小缺陷检测 |
