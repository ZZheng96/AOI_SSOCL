# TEST-03 显存场景采样（AC-070）

## 结论：PASS（实测，非估算；OOM 破坏性子项未做，见边界）

整卡 6,144 MiB（GTX 1660 SUPER），各场景整卡峰值与进程口径峰值：

| 场景 | 整卡峰值 MiB | torch 进程峰值 MiB | 说明 |
|---|---|---|---|
| boot（引擎初始化前） | 516 | – | 系统/其他占用基线 |
| train_prepare（30 图训练） | 913 | 276 | 训练期峰值 |
| idle_after_load（装载后空闲） | 691 | 105 | 模型驻留 |
| infer_single（单实例连测 18 张） | 691 | 127 | 与空闲持平：特征驻留 CPU，推理显存增量极小 |
| train_prepare 第二品类（多槽） | 919 | 290 | 双品类驻留 + 训练 |
| idle_two_slots（双品类驻留） | 691 | 110 | 第二品类未增加驻留峰值 |
| infer_dual_process（父子进程同卡并行推理） | 926 | 131 | 整卡口径含两进程 |
| replay_reload（卸载重装载/WAL 回放） | 693 | 114 | 无峰值跳变 |

## 业务上限建议（草案，待用户定值）

- 本卡观测最高 926 MiB（双进程推理+训练交错）。按 3 倍余量：
  - 建议单进程显存预算 **≤1,024 MiB**（torch 口径观测最大 290 MiB，余量充足）。
  - 建议整卡占用告警线 **3,000 MiB**、拒绝线 **4,500 MiB**（6 GB 卡，留系统/显示余量）。
- 拒绝策略草案：后台训练/候选构建前检查整卡已用 > 拒绝线则推迟（deferred）；
  前台推理不拒绝，仅降级（跳过热图渲染）。

## 边界

- 人为制造 OOM 的破坏性复现**未做**（避免在共享开发机上破坏其他进程显存；
  需在专用环境执行后再验证“OOM 后工作态/事件不破坏”）。
- 采样间隔约 100ms（nvidia-smi 进程调用开销使实际间隔 100~150ms）。
- 数值仅对本卡/本代码版本有效；生产目标硬件不同需重测。
- 隔离 TEMP 环境，未改生产 DB/快照。
