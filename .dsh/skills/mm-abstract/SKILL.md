# 摘要撰写（统一摘要页）

## 定位与硬约束

- 华为杯统一摘要页为**纯文字页、无图**，全文（含关键词）≤ 2 页；
- 摘要是评审第一印象：须让评审 30 秒内看到"方法 + 结果 + 定量分析"三要素（评审铁律第 1 条）；
- 摘要里的模型名、符号、数字必须与正文完全一致（评审会逐项核对，不一致直接扣分）。

## 五要素结构与逐段模板句

**1. 建模思路**（1 段）：问题本质 → 切入点 → 总体路线。
> 针对问题 X 的<本质难点>，我们首先<一句话点出问题本质>，进而提出<建模切入点>，并设计<求解路径>。

**2. 主要方法**（1 段）：模型名 + 算法 + 数据/验证手段。
> 综合运用<模型1>、<模型2>与<算法>，采用<5 折交叉验证/仿真校验>保证结果可靠性。

**3. 模型**（半段）：关键模型与公式编号。
> 建立<模型名>（式 (1)），其中<核心变量>；针对<约束>引入<机制>（式 (2)）……

**4. 结果与结论**（1~2 段）：**每问 ≥2 个定量结果**（数字+单位+对比对象），硬数字 `\textbf{}` 加粗。
> 问题一：<方法>得到<结果1>，较<基准>提升/降低 <x%>；……问题二：……；问题三：……
> 并验证模型稳健性（参数扰动 ±20% 排序不变）。

**5. 创新点**（3 条左右）：①首次/②引入/③融合/④改进句式，勿写成口号。

## 总分总段落模板（可直接套用）

> 本文围绕<赛题主题>，针对<核心矛盾>建立了<模型体系>。（总——问题本质+总体路线）
>
> 针对问题一，建立<模型1>，求解得到<结果>（\textbf{硬数字}，较<基准>提升 <x%>）；
> 针对问题二，……；针对问题三，……。（分——每问一段：方法+模型+结果，2~4 个定量数字）
>
> 综上，本文方法在<指标>上优于<基准>，且对关键参数扰动保持稳健；主要创新在于 ①……②……③……。
> （总——结论+稳健性+创新点）

获奖写法参考（2023_A 一等奖）："理论冲突概率 10.46%，仿真 11.03%，相差 0.57%；理论吞吐 67.17 Mbps，仿真 65.46 Mbps，相差 2.55%"——每问"理论 vs 仿真 + 误差"双数字最有说服力。

## 逐问结果回填清单（动笔前先填表）

| 问题 | 方法/模型 | 结果 1（数字+单位+对比） | 结果 2 | 口径（CV/测试集） | 来源文件 |
|---|---|---|---|---|---|
| 一 | <模型1> | <A，较基准升 x%> | <B> | 5 折 CV | data/results/problemX_results.json |
| 二 | <模型2> | <C> | <D> | 测试集 | data/results/experiment_log.csv |
| 三 | <模型3> | <E> | <F> | 5 折 CV | …… |

每格必须填**真实运行数字**（"来源文件"列给出出处）；填不出 = 该问还没跑完，先补实验再写摘要。

## 数字回填（自动化，禁止手编数字）

1. 结果落盘约定：`mmkit.utils.io` 的 `save_metrics/save_df` → `data/results/problem*.json` / `*.csv`；
2. 汇总日志：`python code/scripts/build_manifest.py` → `data/results/experiment_log.csv`（各问题关键指标一行）；
3. 回填示例（数字全部来自运行日志，不是估算）：

```python
import pandas as pd
from mmkit.utils.io import load_json

r = load_json("data/results/problemB_results.json")   # 键名以实际落盘为准
log = pd.read_csv("data/results/experiment_log.csv")
row = log[log["problem"] == "B"].iloc[0]
print(f"问题二：XGBoost 预测 R²={row['r2']:.3f}、RMSE={row['rmse']:.1f}，"
      f"较 EESM（R²={r['eesm_r2']:.2f}）显著提升。")
```

4. 回填后立即把硬数字 `\textbf{}` 加粗，并与正文表格交叉核对。
5. 正文表格由结果 CSV 自动生成，保证与摘要数字同源：`from mmkit.paper.csv2latex import csv_to_tabular` → 生成三线表片段直接 `\input`（见 `mm-latex-paper` / `code/mmkit/paper/csv2latex.py`）；`check_figures.py --report` 可对账图表↔引用。

## 口径纪律（评审红线）

- **摘要/结论只能用 5 折 CV 或测试集指标**；训练集 MAPE/R² 严禁当宣传数字（评审一眼识破，属一票否决级错误）；
- 每问结果必须分开写，禁止"结果良好/精度高"式笼统表述；
- 数字必须带**对比基准**（理论值/基准模型/上一方案），纯数字无对比不算定量结果。

## 自查清单（写完后逐项打勾）

- [ ] 五要素齐全（建模思路/主要方法/模型/结果与结论/创新点）+ 关键词 4~6 个分号分隔；
- [ ] 每问 ≥2 个定量结果（数字+单位+对比对象），硬数字已 `\textbf`；
- [ ] 指标口径为 CV/测试集（来自 experiment_log.csv 或 cv 结果，非训练集）；
- [ ] 全文（含关键词）≤ 2 页；摘要页无图；
- [ ] 摘要数字、模型名与正文表格、正文结论完全一致。

## 常见坑

- 只有"精度高/效果良好"无数字——等于没写结果；
- 创新点漏写（五要素中最易缺）或写成口号；
- 关键词超过 6 个或写成一句话；
- 训练集指标当结果（红线）；摘要数字与正文不一致（评审核对即扣分）；
- 摘要页放图（统一摘要页为纯文字页）。
