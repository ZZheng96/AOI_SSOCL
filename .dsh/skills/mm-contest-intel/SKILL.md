# 竞赛情报速查（华为杯研究生数学建模竞赛）

## 关键信息

- **赛制**：每队 3 人，A–F 六题选一，赛程约 4 天（9 月中下旬）；
- **奖项**：一等奖 ≤1.5%、二等奖 ≤13%、三等奖 ≤20%（获奖率约 34.5%），另有"数模之星"冠亚季军与华为专项奖；
- **论文硬性要求**（2025 华为杯）：
  1. PDF 命名 `题号+队号.pdf`（如 `A25000010001.pdf`）；
  2. 首页为官方封面（含 4 个 logo，不可删除/替换），**除封面外不得出现单位/姓名/队号**；
  3. 第二页起为统一摘要页，摘要 ≤ 2 页，须含五要素：建模思路、主要方法、模型、结果与结论、创新点；
  4. 三步提交：MD5 识别码 → PDF → 附件（rar/zip ≤50MB，命名同论文）；
  5. AI 仅作辅助工具，须在论文中注明 AI 产品来源；引用程序须注明来源；全文查重。

## 使用步骤

1. 赛前：读 `docs/` 与 `PROJECT_PLAN.md` §1，确认当年官方时间窗口（以官方公告为准）；
2. 选题前：确认六题主题（2025 参考：A 调度优化 / B 链路速率 / C 裂隙三维重构 / D 融合路径 / E 振动信号 / F 开放美学）；
3. 提交前：用 `mm-submit-check` 逐项核对格式与时间。

## 常见坑

- 队伍编号在封面以外出现 → 判违规；页眉页脚、附录、代码注释都要查；
- MD5 提交后论文禁止修改；
- AI 使用不声明 → 可能被认定为违规；
- 附件超 50MB 或命名错误 → 无法上传。
