# 题目 → 模型匹配

## 问题类型速查表

| 问题特征 | 首选模型 | 组合套路 |
|---|---|---|
| 打分/排序/比选（有指标无样本） | AHP、熵权、CRITIC | AHP 主观 + 熵权客观 → TOPSIS/GRA/模糊综合评价 → 灵敏度 |
| 打分排序（有大量样本） | PCA/因子 + TOPSIS/聚类 | 降维 → 聚类分档 → 判别验证 |
| 求最优方案/最小成本 | LP、MILP、NLP、DP | 精确解（小规模）→ 元启发式（大规模）→ 帕累托分析 |
| 调度/排程（任务依赖资源） | DAG 调度、MILP、GA/SA | 关键路径下界 → 启发式 → 甘特图 |
| 路径规划 | Dijkstra/A*、Floyd、VRP | 图建模 → 最短路 → 容量/多目标扩展 |
| 时间序列外推 | ARIMA、GM(1,1)、LSTM、梯度提升 | 基准简单模型 → 复杂模型 → 误差对比 |
| 回归预测（有特征） | 线性回归、SVR、XGBoost、LSTM | 特征工程 → 多模型对比 → 灵敏度 |
| 分组/结构发现 | K-means、层次、DBSCAN、GMM | 肘部法选 k → 轮廓系数验证 |
| 影响因素/显著性 | 假设检验、ANOVA、相关分析、回归诊断 | 检验 → 回归 → 共线性/残差诊断 |
| 机理建模（物理/生物） | ODE/PDE、差分方程 | 守恒律建模 → 参数估计 → 稳定性/灵敏度 |
| 图像识别/分割 | CNN、U-Net | 预处理 → 分割 → 几何量提取 |
| 信号分析 | FFT、小波、时序特征 | 时频特征 → 分类/回归 |
| 三维重构 | 点云/网格（pyvista/trimesh） | 分割 → 点云 → ICP → 曲面重建 → 精度评价 |
| 开放/综合题 | 问题解构 + 多方法融合 | 指标量化 → 综合评价 + 空间/机理 + 三角验证 |
| 效率评价（多投入产出） | DEA | CCR/BCC + 规模收益分析 |

## 使用步骤

1. 通读题目，把每一问转成"问题特征"（一句话）；
2. 查上表得到候选模型，优先选"数据量匹配 + 熟悉度高 + 论文好写"的；
3. 为每问确定主模型 + 1 个对比模型 + 1 个灵敏度方法；
4. 到对应模型族 skill 取三件套（README/model.tex/model.py）。

## 常见坑

- 模型复杂度与数据量不匹配（小数据硬上深度学习 → 过拟合且跑不动）；
- 只建模不对比（评审要求"为什么是这个模型"）；
- 忽略模型假设验证（如回归前不做共线性检验）。
